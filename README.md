# Java Notepad Application

A feature-rich **Notepad** application built using **Java**, **JFrame**, **Swing**, and **AWT**. This simple yet powerful text editor includes essential text-editing features, file handling, and clipboard functionality.

## Features

- **Text Editing**: 
  - Copy, Paste, Cut, Select All, Bold, and Italic with **keyboard shortcut support**.
- **File Management**: 
  - Open, Save, and Print `.txt` files, focused on text document handling.
- **Clipboard Functionality**: 
  - Copy text to the clipboard and paste it anywhere in the system.
- **User-Friendly Interface**: 
  - Built using **Java Swing** and **AWT** for a responsive and intuitive GUI.

## Requirements

- Java 8 or higher

## Usage

1. **Open** a `.txt` file from the File menu.
2. Use the provided **editing functions** (copy, paste, cut, bold, italic, etc.) to modify text.
3. **Save** the document to store changes.
4. **Print** the document directly from the File menu.
5. Copy text to the **clipboard** and paste it anywhere within the system.
6. Use **keyboard shortcuts** for faster text editing operations (e.g., `Ctrl + C` for copy, `Ctrl + B` for bold).
